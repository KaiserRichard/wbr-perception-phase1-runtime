# Wiring diagram renderer

Render a spec to SVG, PDF and PNG:

```sh
python tools/wiring_diagram/wiring_diagram.py path/to/wiring.yaml --output-dir path/to/figures --png-width 2400
python tools/wiring_diagram/wiring_diagram.py path/to/wiring.yaml --output-dir path/to/figures --strict
```

Normal mode always writes the drawing and reports every discovered issue. `--strict` returns failure after writing the drawing if any check fails. Violations are printed with wire names and coordinates and marked with magenta circles in the PNG.

## Spec

Top-level fields include `title`, `canvas`, `output`, `parts`, `rails`, `channels`, and `connections`. A channel is a named rectangle with `[x,y,width,height]` bounds, lane orientation (`horizontal` or `vertical`), and optional lane `spacing`:

```yaml
channels:
  above_nucleo:
    bounds: [500, 80, 900, 100]
    axis: horizontal
    spacing: 12
```

Each connection can include `via`: an ordered list of waypoint pairs and/or channel names. Channel lanes are assigned independently in endpoint-coordinate order, so wires in a bundle get parallel tracks with the configured spacing. A channel's bounds describe the coarse shared corridor; its lane offsets are generated by the renderer.

```yaml
connections:
  - id: UART TX
    from: pi.GPIO14
    to: nuc.PA10
    colour: '#ef7d00'
    via: [above_nucleo]
  - id: short jumper
    from: nuc.D4
    to: board.s1
    via: [[1450, 480]]
```

Without `via`, a wire uses a simple two-segment L route (or one segment for aligned pins); self-checks still examine it. The tool checks route endpoints, orthogonality, collinear overlaps, part/text crossings and label collisions. Endpoint labels try positions above, below, left, right and along the wire endpoint, choosing the first free position.

### Worked example

`reports/2026-10-supervisor/figures/src/bench_wiring.yaml` is a complete example: Pi UART and CAN control wires use `above_nucleo`, CAN/IMU lines use `right_bus`, and power/LED routes use `power_gap`. To reproduce:

```sh
reports/2026-10-supervisor/figures/src/.venv/bin/python tools/wiring_diagram/wiring_diagram.py reports/2026-10-supervisor/figures/src/bench_wiring.yaml --output-dir reports/2026-10-supervisor/figures --png-width 2400 --strict
```

## Parts

FZP connector names and IDs resolve through `views/breadboardView/p/@svgId` to the centre of that SVG element's bounding box. `extra_pins` maps names to SVG IDs or `[x,y]` part coordinates. Header grids accept `origin`, `pitch`, `rows`, `cols`, and a Python format `naming` template.
