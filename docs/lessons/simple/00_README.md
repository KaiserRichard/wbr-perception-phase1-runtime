# Sáu bài học đơn giản về robot

Tài liệu này giải thích lại sáu chủ đề trong `docs/lessons/` bằng tiếng Việt dễ đọc. Mỗi bài có từ khoá, lý do cần biết, sơ đồ, một ví dụ tính toán và câu hỏi tự kiểm tra.

## Thứ tự đọc

1. [CAN và RobStride](01_can_robstride.md) — cách các bộ điều khiển trao đổi dữ liệu với động cơ.
2. [micro-ROS trên STM32](02_microros_stm32.md) — cách STM32 nhận và gửi dữ liệu ROS 2.
3. [Firmware đế AGV](03_agv_firmware.md) — cách lệnh chạy được đổi thành tốc độ bánh.
4. [Giữ thăng bằng: LQR và VMC](04_balance_lqr_vmc.md) — cách robot phản ứng và truyền lực tới bánh.
5. [Chuỗi nhảy](05_jump.md) — cách firmware chia thao tác nhảy thành từng bước.
6. [Các tình huống thử nghiệm](06_tests.md) — cách kiểm tra đường truyền theo từng phần.

Các bài đơn giản chỉ rút gọn nội dung từ sáu bài đầy đủ. Dùng liên kết “Muốn đọc sâu hơn” ở cuối mỗi bài để mở phần giải thích chi tiết.
