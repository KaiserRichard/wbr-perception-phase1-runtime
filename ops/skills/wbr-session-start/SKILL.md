# Session start

1. `cd ~/Desktop/Research/wbr-lab-ops && git fetch origin && git status -sb`.
   If there are uncommitted changes from last time, commit them on their branch
   first. New work: `git switch -c chatgpt/$(date +%Y%m%d)-<topic> origin/main`.
2. Read `ops/worklog/CURRENT.md`.
3. Tell the owner in 3–5 lines what's next and start doing it.
