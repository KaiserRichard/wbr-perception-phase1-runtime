# Dense stereo map from MAP-2m-r3

- Added `tools/local_map/dense_from_orb.py`; output is in `dense-out/`.
- Inputs read-only: 25 Oct sensor MCAP and stereo calibration, plus ORB replay pose MCAP.
- Used the supplied Python environment. `cv2` was absent; installed nothing. NumPy fallback performs 5x5 SAD cost matching with four semi-global paths at quarter linear resolution and left-right consistency.
- Default run: every 3rd pair, pose tolerance 20 ms, output pixel stride 3, depth 0.3–3.0 m, voxel 0.01 m, minimum two frames per voxel.
- Result: all 225 selected pairs had a pose; 4,447,683 points before filtering, 556,284 after; extents x=4.660 m, y=4.525 m, z=4.113 m.
- Near-horizontal table-plane candidate (|normal_z| >= 0.85): 21,580 inliers, RMS 0.005766 m.
- Outputs: 19 MB ASCII PLY, 7.0 MB MCAP, 965 KB top-down PNG, Foxglove layout JSON, three-line stats file.
- MCAP inspection decoded `/dense_map` (`map`, float32 xyz/intensity), `/orb/path` (674 poses in `map`), and `/tf_static` (`map -> slam_world`, requested quaternion).
- Debug notes: direct execution first needed repository-root `sys.path`; corrected NumPy scan-axis indexing; vectorized scan lines after the initial scalar fallback was too slow; fixed frame-observation counting and used `mcap.writer.Writer` API for serialization. Final run completed successfully in about 36 s.
- No tests added or run; full requested data pipeline and output inspection were run. Worktree left uncommitted.
