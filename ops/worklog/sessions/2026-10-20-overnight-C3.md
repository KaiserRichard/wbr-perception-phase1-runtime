# C3 documentation link checker

- Added `scripts/check_doc_links.py`, a standard-library checker for Markdown links and explicit repository-root paths in `docs/learning` and `ops`.
- Local references are checked by default. Markdown hrefs resolve relative to their source file, including hrefs beginning with a repository directory; naked/backtick repository paths resolve from repo root. Missing references in worklog sessions/reviews are historical warnings. Other live worklog files fail normally; an explicit `<!-- doc-link-checker: historical -->` marker also opts a document into historical status. Absolute host paths, URLs, fenced examples, template placeholders and glob patterns are excluded from repository-path findings.
- Undefined full/collapsed Markdown reference links are detected. Undefined shortcut references are not detected because `[words]` is ambiguous with bracketed prose.
- Optional HTTP probing has bounded timeouts, at most eight concurrent requests and a 100-URL cap; HTTP 403/429 are reported as unverified. `--http-backend curl` (default) uses the system curl trust store; `--http-backend python` retains urllib probing and includes the underlying TLS/transport reason in unverified output.
- Added regression tests for source-relative hrefs, live worklog files, undefined full reference links, TLS diagnostics, and URL punctuation. `python3 -m unittest discover -s scripts/tests -p test_doc_links.py -v`: original 7/7 passed; follow-up 10/10 passed.
- `python3 scripts/check_doc_links.py --help`: passed. `python3 scripts/check_doc_links.py`: exit 0, zero current broken references and twelve missing repository paths in historical sessions. Examples include a generated build directory, retired simulation paths and `docs/mechanical/shaft_analysis_notes.md`; historical records were preserved.
- Follow-up fixes: regression coverage confirms a root `sim/plant.py` does not make `[plant](sim/plant.py)` valid from `docs/learning`; relative hrefs resolve from their source. Missing `ops/worklog/CURRENT.md` and `README.md` links stay BROKEN while sessions remain historical. URL extraction trims prose punctuation such as the trailing semicolon in a pinned GitHub LICENSE URL.
- `python3 scripts/check_doc_links.py --check-http --timeout 3 --max-urls 100 --jobs 4`: 63 unique URLs probed; 47 returned 2xx/3xx, 16 returned HTTP 404, zero were unverified/timeouts. All 404s target `github.com/KaiserRichard/wbr-perception-phase1-runtime`; GitHub requests are unauthenticated in this checkout, so private-repository 404s are inconclusive and were not treated as broken links or rewritten. Detailed output: `/private/tmp/wbr-overnight-20261020/C3/http-scan.log`.
- Remaining local findings: zero broken, 12 historical warnings from prior session records. Undefined full/collapsed references are checked; ambiguous shortcut references remain unsupported.
