## Residual design and measurement

- [Residual Policy Learning §IV-A](https://arxiv.org/html/1812.06298#S4.SS1) supports zeroing the final layer to start with the base controller. Its manipulation/DDPG results support the idea, not a WBR/PPO guarantee.
- **Zero mean is not zero exploration.** [SB3's Gaussian distribution](https://stable-baselines3.readthedocs.io/en/v2.3.2/_modules/stable_baselines3/common/distributions.html#DiagGaussianDistribution) uses separate `exp(log_std)`. Current −1 implies initial residual SD ≈0.147/0.294 Nm before clipping. Check deterministic zero-residual parity and measure stochastic perturbations separately; do not silently change exploration too.
- Claude's candidate: scale 2, zero actor-output weights/bias, residual penalty $0.5\sum_j(\delta u_j/c_j)^2$, caps 0.4/0.8 Nm. The coefficient is a hypothesis; distinguish it from existing total-command cost. Keep 500 Hz LQR, 100 Hz held corrections, physics/noise and final panel unchanged. No filter/new controller yet.
- Use [SB3 VecMonitor](https://stable-baselines3.readthedocs.io/en/v2.3.2/_modules/stable_baselines3/common/vec_env/vec_monitor.html#VecMonitor) before observation normalization for episode length/return; accumulate reward components per episode. V2 lacks these curves; optimizer loss cannot replace them.

**Recommendation:** after v2, check an untrained deterministic zero-residual controller against LQR, then run one 10–20 min/~200k-step residual pilot; pilot the direct arm before its full run too. Print alive/state/total-command/residual/fall terms; plot length and return versus steps. Proceed only with improving return, no survival collapse and improving precision on separate development seeds (exclude held-out 1000–1019). Flat 10 s length can already be the ceiling. Keep final evaluation untouched and report all seeds. LQR 160/160 leaves no strict-success headroom; existing effort/recovery metrics are descriptive, not a switched primary endpoint.
