
USAGE: 

   rs-data-collect  [--] [--version] [-h] [--debug] [--eth] [--eth-only]
                    [--no-eth] [--domain-id <0-232>] [-t <seconds>] [-m <>]
                    [-f <path>] [-c <path>] [-s <serial_number>]


Where: 

   --,  --ignore_rest
     Ignores the rest of the labeled arguments following this flag.

   --version
     Displays version information and exits.

   -h,  --help
     Displays usage information and exits.

   --debug
     Turn on librealsense debug logs

   --eth
     Detect DDS devices, even if disabled in the configuration.

     NOTE - ignored when not built with DDS support

   --eth-only
     Use ONLY DDS devices; do not look for USB/MIPI devices.

     NOTE - ignored when not built with DDS support

   --no-eth
     Do not detect DDS devices, even if enabled in the configuration.

     NOTE - no-op when not built with DDS support

   --domain-id <0-232>
     Domain ID to use with DDS devices.

     NOTE - ignored when not built with DDS support

   -t <seconds>,  --Timeout <seconds>
     Max amount of time to receive frames (in seconds)

   -m <>,  --MaxFrames_Number <>
     Maximum number of frames-per-stream to receive

   -f <path>,  --FullFilePath <path>
     the file where the data will be saved to

   -c <path>,  --ConfigurationFile <path>
     Specify file path with the requested configuration

   -s <serial_number>,  --SerialNumber <serial_number>
     the device Serial Number


   librealsense rs-data-collect tool
